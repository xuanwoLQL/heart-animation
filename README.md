# 爱心粒子动画（单文件）

一个 HTML5 Canvas 粒子爱心动画，全部代码写在一个 `heart.html` 里，**零依赖、零构建**，双击就能跑。

## 效果

- 心形由参数方程生成：`x = 16sin³t`，`y = -(13cos t − 5cos 2t − 2cos 3t − cos 4t)`
- 5 组颜色分别对应轮廓、边缘扩散、内部、原生光晕、全局光晕
- 粒子按指数分布（`-λ·ln(rand)`）向心收缩，形成从边缘向内心聚拢的扩散感
- 自发光叠加 + 全局光晕，黑色背景，右侧/窄屏自动缩放
- 打开浏览器控制台还有一颗 ASCII 爱心彩蛋

## 运行

直接双击 `heart.html`，或用任意浏览器打开。不需要安装任何东西，也没有外部请求——整个文件不引用任何 JS/CSS/图片资源。

## 说明

单文件实现，无第三方依赖。视觉风格参考了开源爱心代码项目（原版为 5 色配色），代码为重新实现。
